# Installation und Updates

1. In HACS das Repository als benutzerdefiniertes Repository vom Typ Integration hinzufügen.
2. Herunterladen und Home Assistant neu starten.
3. Unter Einstellungen → Geräte & Dienste → Integration hinzufügen nach **Stiegensteuerung** suchen und hinzufügen.

Bei einem HACS-Update auf **Aktualisieren** klicken. Falls Home Assistant einen Neustart anfordert, diesen ausführen. Die Integration installiert die Vorlagen beim Start an ihren festen Pfaden. Bestehende Instanzen an diesen Pfaden behalten ihre Eingaben. Eine neue Installation muss ihre Automationen oder Skripte einmal aus den Vorlagen erstellen und die Entitäten auswählen.

Die Vorlage ersetzt keine Tor-Sicherheitsfunktion. Den manuellen Notbetrieb erst mit unabhängigen und geprüften Rückmeldungen in Betrieb nehmen.
